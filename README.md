# 📊 ElectroGlobal Executive Dashboard (Power BI)

## 🚀 Project Overview
This advanced executive dashboard is built for **ElectroGlobal Inc.** as part of a senior data analyst certification scenario. The project involves end-to-end data modeling, star schema architecture, and complex DAX calculations across multiple relational tables (`Fact_Sales`, `Dim_Product`, `Dim_Customer`, `Dim_Store`, `Dim_Date`).

## 🛠️ Tools & Technologies Used
* **Power BI Desktop:** Advanced data modeling, Star Schema design, relationships, and complex DAX measures.
* **Excel / Power Query:** Multi-source data cleaning, transformation, and custom column generation (e.g., Price Tier, Order Status).

## 📌 Key Performance Indicators (KPIs)
* **Total Net Revenue:** $5.91M
* **Gross Profit Margin %:** 44.80%
* **YoY Revenue Growth %:** 2.18%
* **Total COGS:** $3.26M

## 📈 Dashboard Sections & Key Visuals
1. **Executive Cards:** Net Revenue, Margin %, YoY Growth %, and COGS KPIs.
2. **Revenue & Margin % Trend:** Line chart analyzing performance over years and months.
3. **Category & SubCategory Performance:** Detailed matrix breakdown of financial metrics.
4. **Channel Dynamics:** Donut chart analyzing revenue breakdown by Sales Type (Online vs In-Store).
5. **Geographical Analysis:** Map visual tracking revenue by store country and city.
6. **Product Performance:** Scatter plot comparing Margin % vs. Quantity by product.
7. **Return Rate Analysis:** Bar chart showing return percentages across product categories.

## 💡 Business Insights & Takeaways
* **Online vs. In-Store Sales** show a balanced revenue contribution (Online at $2.90M vs In-Store at $3.00M).
* **Overall Return Rate** stands at 9.4% of total orders.
* **Star Schema Architecture** ensures optimized filter performance across all dimension tables.
